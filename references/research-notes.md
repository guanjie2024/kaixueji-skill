# 开学季活动策划 · 调研笔记

> 本 skill 是**领域内容生成**型 skill，基于中国学校开学季的通用活动惯例与各学段文案风格整理。

## 一、开学季的时间与场景

- 秋季开学（9 月）为主，春季开学（2-3 月）为辅。
- 典型场景：开学典礼、新生迎新、主题班会、家长会、开学第一课。

## 二、五大输出模式的常规结构

1. **活动方案**：主题 → 目标 → 时间/地点/对象 → 流程 → 物料 → 分工 → 预算 → 应急预案 → 宣传。
2. **主题·标语·文案**：主题（一句话定调）+ 标语（对仗、好记、可挂横幅）+ 文案（横幅/海报/朋友圈/公众号）。
3. **主持词**：开场 → 介绍人员 → 议程 → 环节串联 → 结束寄语。
4. **演讲稿**：校长（寄语式）、教师代表（温情责任式）、学生代表（朝气决心式）。
5. **开学第一课**：安全教育、心理健康、习惯养成、思政价值观、收心目标 五大方向。

## 三、学段风格对照（关键）

| 学段 | 基调 | 关键词 | 高频主题 |
|---|---|---|---|
| 幼儿园 | 可爱童趣 | 萌娃、小火车、回笼 | 你好新朋友、牵着你的手 |
| 小学 | 活泼鼓励 | 新书包、新梦想、习惯 | 扬帆起航、快乐成长 |
| 初中 | 热血青春 | 青春、以梦为马 | 向青春出发、不负韶华 |
| 高中 | 拼搏奋斗 | 披荆斩棘、冲刺 | 决胜未来、只争朝夕 |
| 大学 | 独立担当 | 启航、成人、山海 | 从这里走向世界、独立成长 |

## 四、特别说明

- **大学家长会** ≈ 新生家长见面会：语气平等尊重，强调"放手+家校协同"，必讲安全（防诈骗、网贷、心理）。
- **陈词滥调规避**：避免"金秋送爽、丹桂飘香""共创辉煌"等被用烂的套话。

## 五、免责声明

本 skill 提供通用骨架与示例，具体实施需结合当地校情、当年语境，涉及安全/思政内容请校方审核把关。
