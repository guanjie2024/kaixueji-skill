# kaixueji-skill · 开学季活动策划

> 面向学校、老师、班主任、校方的开学季一站式内容库。
> 方案、文案标语、主持词、演讲稿、开学第一课，一次写到位。

输入「学段 + 场景 + 要什么」，输出可直接使用的开学季活动内容。

- 格式：遵循 AgentSkills 规范（`SKILL.md` + YAML frontmatter），兼容 Claude Code / Cursor / OpenClaw 等平台
- 定位：**只服务学校/老师端**，不服务商家/教培营销

## 一、五大输出模式

| 模式 | 输出 |
|---|---|
| ① 活动方案 | 开学典礼 / 迎新 / 班会 / 家长会完整方案（含流程表、物料、分工、预算、应急预案） |
| ② 主题·标语·文案 | 主题、横幅标语、海报/朋友圈/公众号文案 |
| ③ 主持词 | 完整主持词（开场→介绍→议程→串联→结束） |
| ④ 演讲稿 | 校长 / 教师代表 / 学生代表演讲稿 |
| ⑤ 开学第一课 | 安全 / 心理 / 习惯 / 思政 / 目标 五大主题班会 |

## 二、全学段自动适配

| 学段 | 语气 |
|---|---|
| 幼儿园 | 可爱、童趣、拟人 |
| 小学 | 活泼、鼓励、正能量 |
| 初中 | 热血、青春、励志 |
| 高中 | 拼搏、奋斗、冲刺 |
| 大学 | 独立、成长、担当 |

## 三、安装与使用

### 方式 A：Claude Code 等支持 AgentSkills 的平台

```bash
npx skills add guanjie2024/kaixueji-skill
```

### 方式 B：手动安装

把 `SKILL.md` 放到你 Agent 平台的 skills 目录（如 Claude Code 的 `.claude/skills/kaixueji/`）。

### 触发示例

```
> 小学开学典礼，要一套主持词 + 标语
> 大学家长会怎么主持？
> 初中开学第一课，做安全教育主题班会
> 幼儿园新学期，帮我起 10 个标语
```
